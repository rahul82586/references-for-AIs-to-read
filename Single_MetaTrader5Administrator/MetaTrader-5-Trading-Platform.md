# The guide for installing, configuring and working with MetaTrader 5.

MetaTrader 5 is an advanced complete-cycle multi-asset trading platform for organizing brokerage services.

You traders can perform operations on different markets and exchanges using a single account. The flexible trading systems enables the highly efficient management of all asset types, including currencies, futures and stocks. In addition to essential trading features, you can offer professional technical and fundamental analysis tools to your traders, as well as the ability to use algorithmic trading robots.

The distributed platform architecture can handle high loads allowing companies to provide services to hundreds of thousands of online users. The system has built-in failover mechanisms and protection against possible external attacks.

With the advanced back-office system, you can organize the workflow to match your business expectations.

## Installation

Prepare hardware in accordance with the [system requirements](MetaTrader-5-Trading-Platform/Platform-Installation/System-Requirements.md). We recommend using at least two dedicated servers hosted by different providers to implement the main and the backup infrastructures. [Prepare the system](MetaTrader-5-Trading-Platform/Platform-Installation/System-Preparation.md) and proceed to MetaTrader 5 [installation](MetaTrader-5-Trading-Platform/Platform-Installation/Installation.md). After that, [activate the license](MetaTrader-5-Trading-Platform/Platform-Installation/Activation.md) and configure your platform.

Use the [quick deployment](MetaTrader-5-Trading-Platform/Platform-Installation/Fast-Deployment.md) feature to install additional platform components. If you need to move the platform or reconfigure the network infrastructure, use [console commands](MetaTrader-5-Trading-Platform/Platform-Installation/Console-Setup.md).

## Platform Components

The MetaTrader 5 trading platform is a distributed system. The main functions are implemented on different components to enable efficient load balancing, allowing companies to offer services to hundreds of thousands traders.

The components interact via the main trading server which stores all platform settings.

![start_page_trade](images/start_page_trade.png) | [Trading Server](MetaTrader-5-Trading-Platform/Platform-Components/Trade-Server.md) | Two types of trading servers exist in the platform: one main server and additional ones. The main trading server serves trading operations and manages the entire system configuration  
![start_page_access](images/start_page_access.png) | [Access Server](MetaTrader-5-Trading-Platform/Platform-Components/Access-Server.md) | Access servers act as proxy servers and firewalls for the MetaTrader 5 platform. They process incoming client connections, pack and send authorization requests to the trade server, and protect it from attacks and overload  
![start_page_history](images/start_page_history.png) | [History Server](MetaTrader-5-Trading-Platform/Platform-Components/History-Server.md) | The history server processes price and news data. It receives and filters quotes from gateways and data feeds, as well as stores and provides trading history in the form of one-minute bars and ticks to other platform components  
![start_page_backup](images/start_page_backup.png) | [Backup Server](MetaTrader-5-Trading-Platform/Platform-Components/Backup-Server.md) | It creates backup copies of data that can be used in case of failure of a trading or history server. One or more backup servers are associated with each trading server. They synchronize their states with the main server in real-time mode, and thus you can instantly switch to them in case of failure. Also, backup servers create periodic copies of databases which can be used to restore the system state as of the required day  
![start_page_datafeed](images/start_page_datafeed_1.png) | [Data Feeds](MetaTrader-5-Trading-Platform/Platform-Components/Data-Feeds.md) | Deliver quotes and news into the platform. The trading platform includes more than a dozed out-of-the-box data feeds which enable connections to popular data providers  
![start_page_gateway](images/start_page_gateway_1.png) | [Gateways](MetaTrader-5-Trading-Platform/Platform-Components/Gateways.md) | The gateways integrate the MetaTrader 5 platform with external trading systems and liquidity providers. They can forward trading operations to external systems, as well as broadcast quotes and news from them  
![start_page_webterminal](images/start_page_webterminal.png) | [WebTerminal](MetaTrader-5-Trading-Platform/Platform-Components/WebTerminal.md) | The web terminal allows trading in financial markets from any web browser. The rich set of functions that are available in the desktop platform can be accessed directly on the web, without downloading or installing any application. To connect the web terminal, request it from the [App Store](https://support.metaquotes.net/en/market) on the technical support site
